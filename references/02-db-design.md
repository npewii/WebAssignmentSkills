# 02 数据库的设计

原始PPT文件名：课件——02 数据库的设计.pptx

## 主题与关键点
- 数据库类型概览：RDBMS / NewSQL / NoSQL / OLAP
- ACID 及其适用场景：批量导入等需要事务一致性
- MySQL 选择依据与引擎对比（InnoDB/MyISAM/Memory/Archive）
- SQL 四种语言分类
- ER图：实体、属性、联系（1:1 / 1:n / m:n）
- ER图到关系模型转换套路
- 实体 vs 属性辨析：根据业务核心与引用关系判断
- 物理优化原则与实体清单

## 关键方法论
- 1:n 关系在 n 端增加对方主键
- m:n 关系需要独立关系表（联合主键）
- 关系模型到物理模型：字段类型、索引、约束

## 常见检查点
- 实体与属性是否混淆（如“密码”通常是属性）
- 关系转换是否把对方主键放在正确的一端
- 是否考虑后续业务流程（登录、成绩、任务等）
