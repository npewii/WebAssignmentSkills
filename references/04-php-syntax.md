# 04 PHP语法概述

原始PPT文件名：课件——04 PHP语法概述.pptx

## 主题与关键点
- PHP标记与结束标签；短输出标签 <?=
- 分号与隐含分号
- 注释规范：单行/多行，类和函数要写注释
- 输出：echo/print_r/var_dump；API常用 echo json_encode
- 数据类型与判断函数（gettype/is_string/is_int 等）
- 变量规则：$ 开头，区分大小写，字母/下划线起始
- 超全局变量：$_GET/$_POST/$_SERVER/$_SESSION 等
- 数组：增删改查、遍历、排序、拆分合并、查找
- JSON 与数组互转
- 运算符与优先级
- 条件语句与循环
- PHP编码规范：总体/命名/控制结构/数据库应用

## 作业与提交
### 作业一
- Postman 创建 GET 请求，传 name 与 age 参数
- 读取参数写入数组
- 输出 JSON 响应（格式见PPT）
- HTTP状态码 200

### 作业一优化
- 缺 name：状态码 400、业务码 1001、提示信息
- 缺 age：状态码 400、业务码 1002、提示信息
- 两者都缺：状态码 400、业务码 1003、提示信息

### 作业二
- 用二维数组存储 5 个学生姓名与成绩
- 循环处理并输出 JSON
- 内容：班级平均分、最高分与最低分学生

### 作业三（课后）
- 简易学生信息管理系统（数组存储）
- 学生列表展示、添加、删除、搜索（编辑可选）

## 常见检查点
- JSON响应必须结构一致
- 输入缺失时返回 400 + 对应业务码
- 数组遍历与统计时注意边界条件
