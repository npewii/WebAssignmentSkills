# 07 RESTful风格的API设计

原始PPT文件名：课件——07 RESTful风格的API设计.pptx

## 主题与关键点
- API 的定义与价值：请求/响应 + 注释规范
- RESTful 6 大核心原则
- 统一接口四子约束：资源识别、通过表述操作资源、自描述消息、HATEOAS
- 资源命名规则：复数名词、小写+连字符、多级资源
- HTTP 方法与状态码使用
- 无状态与缓存；教务系统场景下 Session 可行
- API 文档工具：Apifox

## 常见检查点
- RESTful URL 使用复数名词
- 用 HTTP 动词表达意图，而不是动词化路径
- 状态码与业务码区分清楚
