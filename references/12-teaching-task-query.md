# 12 教学任务查询功能的实现

原始PPT文件名：课件——12 教学任务查询功能的实现.pptx

## 主题与关键点
- 教学任务查询的需求分析（教师/学生）
- 请求参数设计：fromterm、toterm（学年学期格式：252602）
- 请求头与响应体设计、教学任务查询API设计
- Task 类编程分析与 search 逻辑
- task 表索引设计：首要条件为班级编号或工号，次要条件为学年学期
- 缓存控制：强缓存与协商缓存（Cache-Control、If-Modified-Since、304）
- Sess 类缓存控制方法与 gmdate 用法
- task/score 表新增“最后修改时间”字段（练习）

## 常见检查点
- fromterm/toterm 格式与范围是否正确
- 请求头参数与响应体字段是否按PPT一致
- 缓存控制是否返回 304 且客户端缓存生效
- Task 查询条件优先级是否正确（班级/工号优先，学年学期次之）
