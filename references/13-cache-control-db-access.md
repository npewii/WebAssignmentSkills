# 13 缓存控制和数据库访问控制

原始PPT文件名：课件——13 缓存控制和数据库访问控制.pptx

## 主题与关键点
- 缓存控制的三个层面与缓存生命周期
- 强缓存与协商缓存：Cache-Control、If-Modified-Since、304
- gmdate 与 HTTP 时间（RFC1123）
- TimeTool 工具类：学年学期格式校验（252602）、时间戳转 HTTP 时间、获取当前学年学期
- task/score 表新增“最后修改时间”字段
- Sess 类缓存控制方法、Task::search 增加缓存逻辑
- 教师/学生查询请求的缓存结果示例
- 数据库访问控制方案对比：数据库用户级 vs 应用层控制
- 最小权限原则：只读、读+改、读+插入
