什么是路由分发

[图片：路由分发就是指：根据请求的 HTTP 方法（GET、POST、PATCH、DELETE）和 URI 路径（如 /sessions、/users、/tasks），将请求分发给对应的业务逻辑模块进行处理。]

[图片：两种URL路由方式：
● 基于文件路径：访问 /user/login.php 直接对应服务器上的 user/login.php 文件，适用于小型网站、简单脚本
● 基于入口文件：所有请求都指向 index.php，由 PHP 脚本解析 URI 后分发给对应的类和方法，适用于 REST API、MVC 框架]

<!-- Slide number: 5 -->
路由分发的核心设计

[图片：本系统的路由分发功能通过一个核心工具类 Route 来实现。该类的主要职责包括：
● 请求方法校验：判断 HTTP 方法是否为允许的 GET、POST、PATCH、DELETE
● 资源标识解析：从请求 URI 中提取资源名称（如 sessions、users、tasks）
● 业务逻辑分发：根据资源名称和方法类型，调用对应的处理类和方法]

Router类的实现

[图片：Route.php 代码——run() 方法（第41-69行）：
public function run() {
    // 设置请求方法
    $this->setMethod();
    // 设置资源名称和资源URI
    $this->setResource();

    // 根据资源名称分发到对应逻辑
    switch ($this->_requestResource) {
        case 'sessions':
            // 登录注销逻辑
            $this->dealSessions();
            break;
        case 'users':
            // 用户逻辑
            $this->dealUsers();
            break;
        case 'tasks':
            // 教学任务逻辑
            $this->dealTasks();
            break;
        default:
            throw new Exception('请求的资源不被允许', 405);
    }
}
]

[图片：Route.php 代码——setResource() 方法（第81-99行）：
/**
 * 处理资源
 */
private function setResource() {
    $path = $_SERVER['PATH_INFO'];
    $params = explode('/', $path);
    if (!isset($params[1])) {
        throw new Exception('请求资源不被允许', 405);
    }

    $this->_requestResource = strtolower($params[1]);
    if (!in_array($this->_requestResource, $this->_allowResource)) {
        throw new Exception('请求资源不被允许', 405);
    }

    $this->_requestUri = isset($params[2]) ? strtolower($params[2]) : null;
}
]

[图片：Route.php 代码——setMethod() 方法（第70-78行）：
/**
 * API 请求方法设置
 */
private function setMethod() {
    $this->_requestMethod = strtoupper($_SERVER['REQUEST_METHOD']);
    if (!in_array($this->_requestMethod, $this->_allowRequestMethod)) {
        throw new Exception('请求方法不被允许', 405);
    }
}
]

private function dealSessions() {

[图片：Route.php 代码——dologout() 方法（第140-151行）：
/**
 * 处理注销
 * @return string
 */
private function dologout() {
    try {
        return User::logOut();
    } catch (\Throwable $th) {
        return ApiResponse::error($th->getCode(), $th->getMessage(), $th->getCode());
    }
}
]

[图片：Route.php 代码——doLogin() 方法（第116-138行）：
/**
 * 登录验证执行
 * @return string
 */
private function doLogin() {
    try {
        $data = InputTool::dealJson();
        InputTool::checkId($data['uid']);
        InputTool::checkPwd($data['upassword']);
        InputTool::checkRole($data['urole']);

        $db = DB::getInstance();
        if (strtolower($data['urole']) == 'stu') {
            $user = new Stu($db);
        } else {
            $user = new Te($db);
        }
        return $user->login($data);
    } catch (\Throwable $th) {
        return ApiResponse::error($th->getCode(), $th->getMessage(), $th->getCode());
    }
}
]
